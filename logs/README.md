# Logs directory for mistral.rs bridge mode

Runtime logs from bridge host, remote workers, and benchmarks.
Log naming convention: `<topology>_<model>_<date>_<time>.log`

Examples:
- `wsl_bridge_worker_qwen2_0.5b_20260725_011600.log`
- `gpu_bridge_host_qwen2_0.5b_20260725_011600.log`
- `phone_remote_worker_qwen3_1.7b_20260725_020000.log`
